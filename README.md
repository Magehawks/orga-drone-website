# Orga Drone website

Static landing page for [Orga Drone](https://github.com/Magehawks/orga-drone).

## Local preview

Open `index.html` in a browser. No build step, dependencies or backend.

## Publishing

1. Merge the landing-page PR into `main`.
2. Under **Settings → Pages → Build and deployment**, select **GitHub Actions**.
3. Deploy at https://magehawks.github.io/orga-drone-website/.

## Before promotion

- Replace the generic itch.io profile link with the verified direct product URL.
- Add real application screenshots when available; the hero artwork is labeled as a concept illustration.
- Review product copy and current distribution options.

The website is maintained separately from the desktop application.
